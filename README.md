### About Me

I'm a Data Engineer based in Romania, specializing in designing,
building, and optimizing scalable data pipelines and cloud-native
data platforms.

My experience focuses on processing large volumes of data,
developing real-time streaming architectures, and delivering
reliable data solutions for analytics and business reporting.

I enjoy solving complex engineering challenges involving
distributed systems, data consistency, performance optimization,
and production reliability.

- Building batch and real-time data pipelines with Apache Spark
- Designing event-driven architectures using Apache Kafka
- Developing cloud-native data solutions on AWS
- Working with Data Lakes, Apache Iceberg, and SQL analytics
- Optimizing streaming throughput, partitioning, and scalability
- Implementing data quality, monitoring, and orchestration
- Experienced in Java, Scala, SQL, and Python
